# One Hit Wonders Analytics Platform

A mobile-first analytics application that transforms over a decade of softball statistics into an interactive reporting and historical analysis platform.

The project demonstrates how structured historical data can be modeled, aggregated, and presented through an intuitive web interface using **Google Sheets**, **Google Sheets Query Language (SQL-like)**, and **JavaScript**, resulting in a self-service analytics experience deployed on **GitHub Pages**.

## Overview

One Hit Wonders Analytics Platform is a historical statistics and reporting application built for an amateur softball team.

The application consolidates more than a decade of player, game, and season data into an interactive analytics platform featuring player profiles, historical leaderboards, advanced sabermetric calculations, season summaries, opponent analysis, and game-by-game drilldowns.

Rather than relying on manually maintained spreadsheets, the application provides a centralized interface for exploring team history through interactive reports and visualizations.
